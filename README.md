## 📙 Descripción
**DATAMARK** es una plataforma diseñada para digitalizar pequeños y medianos negocios. Transformamos la captura de ventas mediante Inteligencia Artificial (Voz y NLP) en dashboards analíticos potentes.

> 🌐 **Prueba la Aplicación**: [DATAMARK en Streamlit Cloud](https://datamark-analytics.streamlit.app/)
